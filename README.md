# IntelliFind — Frontend Demo

A responsive lost-and-found frontend built with plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser.

No framework, build step, backend or database is required. Reports are stored in the browser using LocalStorage, so they remain on the same browser/device only. The sample listings and matching percentage are demo content; no real intelligent matching or cross-user sync is connected yet.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — modal forms, search, reports and LocalStorage
